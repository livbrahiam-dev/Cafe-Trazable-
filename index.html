¿Cómo se contrata?

  1. Selecciona un plan mensual.
  2. Se abrirá el enlace de pago seguro cuando el administrador configure el producto en la plataforma de pagos.
  3. Después de confirmar el pago, el administrador debe habilitar la cuenta del cliente.

Estado actual: esta sección presenta los planes, pero todavía no procesa pagos ni bloquea el acceso por falta de pago. Para activar cobros reales se deben crear los planes en Whop, Hotmart o Gumroad, pegar aquí los enlaces de pago y conectar una base de datos con inicio de sesión y validación de suscripciones.

Pasos recomendados para este proyecto

  1. Probar el registro de los cinco lotes simulados y crear un lote nuevo.
  2. Verificar la búsqueda por código, la generación de QR, la trazabilidad hacia atrás y hacia adelante, y el simulacro de retiro.
  3. Guardar el archivo de la aplicación y un README en un repositorio de GitHub.
  4. Publicar la versión web en Netlify o Vercel. Streamlit requiere convertir el proyecto a Python.
  5. Configurar los enlaces de pago de los planes mensuales y conectar usuarios, permisos, base de datos y copias de seguridad antes de vender el acceso.

Importante: el prototipo guarda los datos en el almacenamiento local del navegador. No sincroniza automáticamente la información entre distintos usuarios o dispositivos. La suscripción mostrada es una propuesta comercial; todavía no cobra ni restringe el acceso automáticamente.
